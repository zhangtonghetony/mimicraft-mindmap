## Contract boundaries

- 「主题」始终添加根级分支，「细分主题」添加到当前节点下。
- 同一文档支持中心树与自由主题森林；不做未定义的跨文件实时主题链接。
- 外部 HTML 粘贴按纯文字处理；应用内结构化剪贴板保留内部内容并重映射引用。
- 系统剪贴板拒绝时，应用会话内仍可复制粘贴；跨浏览器/刷新后的内存剪贴板不保证保留。
- 自动保存只属于当前来源，下载为显式快照；下载不自动覆盖已有磁盘文件。
- 相同任务/提醒时间在当前会话只提示一次，刷新后可再次提示；关闭网页不承诺后台提醒。
- 密码保护下载，不保护浏览器明文副本；输出格式映射见 [FORMAT.md](FORMAT.md)。

测试编号对应 app/src/*.test.ts 和 app/tests/*.spec.ts 中的实际断言；多个合同可放在一个测试中。完整验收口径见 [VALIDATION.md](VALIDATION.md)。
